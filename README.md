# Vibe Coding Playbook

> **AI 开发实战手册**：真实项目里让 Agent 写代码，用到的提示词、文档模板和踩坑记录。全部复制即用。

Vibe Coding 不是闭眼让 AI 瞎写。

同样一个 Claude Code / Codex / Cursor，有人 6 小时做完一个 iOS App，有人跑一晚上全是返工。差别不在模型，在于**你喂给它什么、怎么定"做完"、什么时候该你拍板**。

这个仓库收的，就是这些"怎么喂、怎么定、怎么拍板"的东西。每一份都来自真实项目，不是网上抄来的模板。

## 第一个案例：微信流 iOS 版，6 小时上线

[微信流](https://github.com/freestylefly/WeChatBridge) 是一个把微信聊天记录转给 AI 的开源工具。iOS 版从定方案到真机验收，大部分活是 Agent 干的。

下面这套提示词，就是当时实际用的：

| # | 内容 | 解决什么问题 |
|---|---|---|
| 01 | [两轮计划提示词](prompts/01-两轮计划提示词.md) | 别一上来就让它写代码。第一轮对齐方向，第二轮出"任何 Agent 拿到就能做完"的开发文档和档期。含原版 + 通用版 |
| 02 | [Agent 工作规则模板](prompts/02-Agent工作规则模板.md) | 在哪改、怎么提交、什么不许碰、验证不了怎么标。防止它乱改、乱提交、谎报通过 |
| 03 | [验收闸门模板](prompts/03-验收闸门模板.md) | 把"体验要好"改成"做了 X，必须看到 Y"。自动验收 / 人工验收 / 交付定义 / 待决问题 |
| 04 | [进度汇报格式](prompts/04-进度汇报格式.md) | 让它每做完一步按固定格式报告。扫一眼就知道进度，不用翻长篇大论 |
| 05 | [微信群聊场景提示词](prompts/05-微信群聊场景提示词.md) | 客户复盘、项目周会、日常摘要、公众号文章提取、视频信息读取、家长群清单、甲方需求留痕。复制给任何 AI 都能用 |

## 四条心得

1. **先实测，再写计划。** Agent 没有你的手机，也没有你的环境。它不知道的事实，你先去摸清楚，写成文档喂给它，别让它猜。
2. **让它列问题，附上默认做法。** 你只管拍板，它不会卡住，也不会偷偷替你做决定。
3. **验收写成能判断对错的句子。** 验证不了的就写「待人工」，不许标通过。Agent 最怕的不是做不到，是做不到还说做到了。
4. **固定汇报格式。** 做了什么、提交是哪个、测了什么、什么没测、下一步、需要我干嘛。

这四条不只适合写 App。写文档、做调研、整理资料，交给 Agent 的长活都能这么用。

## 怎么用

1. 打开对应的文件，复制代码块里的内容。
2. 把【】里的部分换成你自己的项目。
3. 发给你的 Agent（Claude Code、Codex、Cursor、Kimi、豆包都行）。

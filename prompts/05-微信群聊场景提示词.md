# 处理微信群聊的场景提示词

**用法**：先把聊天记录发给 AI（微信流会自动带上；不用微信流的话，复制聊天记录或者传 TXT 也行），再粘贴下面任意一段。

前五个是微信流内置的官方场景，后两个是我自己常用的。

### 通用输出格式

前三个场景都用这个格式收尾：

```
输出以下六项：1. 要点；2. 结论；3. 待办；4. 风险；5. 负责人；6. 截止时间。没有信息的项目明确写"无"。
```

### 1. 客户复盘（客户群、售后群、甲方沟通群）

```
阅读附件里的聊天记录，聚焦客户需求、业务结论、承诺和下一步推进。
输出以下六项：1. 要点；2. 结论；3. 待办；4. 风险；5. 负责人；6. 截止时间。没有信息的项目明确写"无"。
```

### 2. 项目周会（项目群、跨团队协作群）

```
阅读附件里的聊天记录，整理项目进展、决策、阻塞和待办。
输出以下六项：1. 要点；2. 结论；3. 待办；4. 风险；5. 负责人；6. 截止时间。没有信息的项目明确写"无"。
```

### 3. 日常摘要（通用群聊爬楼）

```
阅读附件里的微信聊天记录，按时间线总结重要信息，不要逐条复述。
输出以下六项：1. 要点；2. 结论；3. 待办；4. 风险；5. 负责人；6. 截止时间。没有信息的项目明确写"无"。
```

### 4. 公众号文章提取（资料群、收藏群）

```
读取附件中的聊天记录，找出公众号文章链接或分享卡片，提取标题、公众号、发布时间、正文和图片，并保留原文链接。
按文章逐篇输出 Markdown：标题、公众号、发布时间、核心摘要、正文、图片、原文链接。无法访问的文章明确标记。
```

> 微信流里这个场景会调用「公众号文章提取」技能。直接用的话，要确保你的 AI 能打开网页。

### 5. 视频信息读取（常分享视频的群）

```
读取附件中的聊天记录，找出视频链接或本地视频文件，提取可获得的逐字稿、摘要、关键结论和时间点，并保留来源。
输出来源、时长、逐字稿或摘要、关键结论、关键时间点和无法读取的部分。
```

> 微信流里这个场景会调用「视频信息读取」技能。直接用的话，要确保你的 AI 能读取视频。

### 6. 家长群清单（补充）

```
阅读附件里的家长群聊天记录，忽略"收到""谢谢老师"这类回复，只整理老师发的通知。
按日期列一张清单：哪天、要交什么、要带什么、几点到、截止时间。
最后单独列出"需要家长回复或签字"的事项。没有的项目写"无"，不要编。
```

### 7. 甲方需求留痕（接单、外包沟通）

```
阅读附件里和甲方的聊天记录，按时间顺序整理需求的每一次变化：
1. 每次改了什么（附原话和时间）；
2. 目前最终确认的版本是哪一个；
3. 还没确认、互相矛盾的地方；
4. 我方答应过的事和期限。
只根据聊天记录写，没有依据的不要推测。
```

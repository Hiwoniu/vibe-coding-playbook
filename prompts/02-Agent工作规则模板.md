# 给 Agent 的工作规则模板

**用法**：放进开发文档的第一节，或者直接贴在任务提示词最前面。

```
给执行者的工作规则（必须遵守）：

1. 工作位置：只在【目录 / 分支】里改。
2. 不要碰：【不能动的目录、文件、未提交的改动】。
3. 提交规则：每个任务完成并通过验收后单独提交，标题以【前缀，例如 [AI]】开头。不 push、不开 PR，除非我在对话里明确要求。
4. 不能退化：改到【已有模块】必须先跑【测试命令】，结果是【基线数量】个测试 0 失败。新增测试后，基线相应增加。
5. 不能验证的就写明没验证：需要人来做的验证，在【验收记录文件】里标「待人工」，不要标通过。
6. 这一版不做：【列出明确不做的功能】。
```
